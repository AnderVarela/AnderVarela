## 👋 About me

I'm a Frontend Developer who thinks like a full-stack engineer. I care about the problems that quietly cost teams weeks: UIs that fall apart because of poor state management, fragile code that breaks production, and frontend and backend teams that don't agree on an API contract.

My approach is to remove those risks from the first commit: **predictable UI architecture, strict typing, and automated quality checks**, so the team can spend its time delivering value instead of fighting regressions.

I hold a Master's degree in Computer Engineering (MUEI) from the Universidade da Coruña, and my Master's thesis was graded **10 with Matrícula de Honor**.

## 🚀 Featured work

### RequiFy · HTTP request mocking tool

Frontend teams often wait weeks for backend APIs to be ready. **RequiFy** removes that dependency: I built it from scratch as a **Chrome extension (Manifest V3)** plus a **SPA** that simulates complex HTTP requests, including latency and response patterns.

It was my Master's thesis and received the top grade (**10, Matrícula de Honor**).

`Chrome Extension (MV3)` `SPA` `TypeScript` `React`
